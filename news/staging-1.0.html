6703OS-staging-1.0 is pending

The 6703OS-staging-1.0 release is pending. Printer compatibility testing covers two Canon printers.

Printers under test

Follow-up validation process

Further validation should record the test build, printer connection method, driver configuration, and date for each result.

  1. Prepare a 6703OS test system and record the printer connection method and driver configuration.
  2. Connect each printer and check whether 6703OS detects it and makes the appropriate driver available.
  3. Send text and image test pages, then check that the jobs complete and the printed output is legible.
  4. Repeat print jobs and connection checks after restarting the system; record errors and any required setup steps.
